# 📊 CodeAlpha - Unemployment Analysis in India

## Project Overview
This project analyzes unemployment trends in India using Python. 
The objective is to study the overall unemployment pattern and investigate the impact of Covid-19 on employment levels.

##  Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- SciPy

##  Dataset
The dataset contains:
- Region (State)
- Date
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Area (Urban/Rural)

## Analysis Performed
✔ Data Cleaning  
✔ National Trend Visualization  
✔ Pre vs Post Covid Comparison  
✔ Seasonal Trend Analysis  
✔ State-wise Unemployment Comparison  
✔ Statistical Significance Testing  

## Key Findings
- Pre-Covid unemployment average ≈ 9.5%
- During lockdown, unemployment sharply increased above 24%
- Post-Covid unemployment remained significantly higher
- Statistical test confirmed significant impact
- Certain states showed consistently higher unemployment

## Conclusion
The Covid-19 pandemic had a statistically significant impact on unemployment rates in India. 
The findings highlight the need for stronger employment protection policies during economic shocks.
